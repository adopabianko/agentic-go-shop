## Behavior delivered

- `(*memory.Store).ReadOrders` reads a consistent snapshot under the store mutex, filters by optional `customer_id`, and returns isolated order/item values sorted ascending by `(created_at, id)`.
- Keyset pages use the normalized `limit`, look ahead for another result, return a non-nil empty `items` slice, and leave `next_cursor` empty on the last page.
- Cursors are unpadded base64url JSON with the frozen version, timestamp, order ID, and bound customer filter. Invalid encoding, length, JSON shape/types/duplicates, version, timestamp, identifier, and filter binding return `domain.ErrInvalid`.
- Tests cover identical timestamps, multiple pages, a new order appearing after a prior page, customer filtering, malformed cursors, result mutation isolation, empty pages, cancellation, and concurrent create/read behavior.
