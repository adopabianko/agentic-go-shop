## Behavior delivered

`AdjustmentHandler` accepts the draft `POST /v1/inventory/{sku}/adjustments` request shape and delegates exactly once to `contracts.AdjustmentUseCase`. It passes the path SKU, exact reason, quantity, request context, and sole idempotency key. Successful create and replay responses return the receipt with status 201 and the corresponding `Idempotency-Replayed` header, without a `Location` header.

The handler reuses the baseline response helpers for the JSON error envelope and application-error mapping. It enforces `application/json`, the 16 KiB limit, unknown-field rejection, one JSON value, and exactly one `Idempotency-Key` header value.
