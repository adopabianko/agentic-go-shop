## Behavior delivered

`adjustments.New(repository)` returns a service implementing `contracts.AdjustmentUseCase`, checked at compile time. `Adjust` uses the baseline key/SKU validators, accepts quantity 1..1,000,000, and requires 1..200 printable ASCII characters in reason. Spaces, case, and punctuation are preserved exactly, including an all-space reason.

Invalid input returns a zero receipt, false replay flag, and `domain.ErrInvalid` without calling the repository. Valid input passes the original context, key, and payload to `ApplyAdjustment` exactly once. The receipt, replay flag, and error are returned unchanged. The service has no retry, response cache, transaction, stock reservation, HTTP call, or receipt generation; atomic stock limits and idempotency remain repository responsibilities.

Tests cover key/SKU length and syntax, quantity bounds, all printable ASCII, all ASCII control characters and DEL, Unicode/invalid UTF-8 rejection, exact reason preservation, success/replay, domain errors, interruption errors, wrapped errors, and unexpected repository failures. Repeated calls still consult the repository once per call.
